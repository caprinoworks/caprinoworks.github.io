# Caprino Works

Static portfolio website. English is the default language; PT switches to Portuguese. The language choice is kept during the browser session. Video project titles retain their original wording.

## Upload to GitHub

Create a repository and upload all files in this folder, keeping index.html at the repository root. No build step or dependencies are required. Do not upload the parent project folder.

## Publish with GitHub Pages

In Settings > Pages, choose Deploy from a branch, main, and / (root). Save and use the URL GitHub provides. All local page and asset links are relative, including project subpaths.

## Cloudflare

The same files can be uploaded as static assets. For Git integration, use the repository root as the output directory; there is no build command.

## Media

Video embeds use Vimeo and YouTube. Some animation videos and covers remain hosted on Wix; keep those source files available. Included background animations are in assets/. This package does not include private credentials, managed-site configuration or the original editing projects.
